# Pre-launch recommendation: headless run checks

## Goal

Exercise launch-critical flows without relying on browser playthroughs.

## Run matrix

- Fresh run: write, study, unlock the writing guide, find a show, and verify the first ordered study result.
- Open-to-Elenco run: perform enough shows to see the 6–7 minute venue bridge, reach level 6, and schedule a 15-minute Elenco circuit gig.
- Class run: qualify for a class path, resolve both career events, and reach the matching ending.
- No-class run: avoid class qualification and verify the generic, almost, or failure ending resolution.
- Persistence run: save, reload, continue a scheduled show, and start a new run from the ending shell.

## Acceptance checks

- No blank dialogs, impossible choices, or stuck pending events.
- Every scheduled gig resolves to a valid show and image.
- Ending state locks gameplay until a valid ending action is chosen.
- A new run does not inherit active-run stats or mentor-owned unlocks.
